记录一下我学习 agent 学习的路程，希望与时俱进，有所建树。

## 贪吃蛇网页游戏

仓库内包含一个零依赖的霓虹风格贪吃蛇游戏，使用原生 HTML、CSS 和 JavaScript 开发。

### 运行

直接双击打开 `index.html`，或在仓库根目录启动任意静态文件服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

### 操作

- 方向键或 `WASD`：控制方向
- `Space`：暂停 / 继续
- `R`：重新开始
- 手机端：使用屏幕方向键，或直接在棋盘上滑动

每吃到一颗能量点获得 10 分。每累计 50 分提升一级，移动速度会逐渐加快；最高分会保存在浏览器本地。
